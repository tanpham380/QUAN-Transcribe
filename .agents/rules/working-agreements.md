# Working agreements

## Before you change anything

- Read the module docstring of the file you are about to edit. Several modules
  (`app/core.py`, `app/vad.py`, `app/audio.py`) open with a rationale section
  that explains why the current design exists. Most "obvious improvements" to
  those files were already considered and rejected for a stated reason.
- Run `pytest -q` before and after. It is fast, needs no GPU, and needs no model
  download.

## Invariants you must not break

1. **One thread owns the model.** All model access goes through `EngineCore` in
   `app/core.py`. Never call the model from a request thread.
2. **`EngineBusy` → HTTP 503 is intentional backpressure.** Do not make the bulk
   queue unbounded.
3. **VAD never runs on the model thread**, and a missing `silero-vad` degrades
   to energy-based splitting instead of failing.
4. **`app/audio.py` cut points must match `quan_transcribe/audio.py`.** Segment
   timestamps depend on it.
5. **Tests never import `torch` or `quan_transcribe`.** Keep the fake-engine
   pattern in `tests/test_app.py`.

## Validation

```bash
pytest -q                          # full suite
pytest -q tests/test_app.py -k <name>
ruff check app tests scripts
ruff format app tests scripts
```

Run the smallest command that covers your change. Escalate to the full suite
when you touch `app/core.py`, `app/engine.py` or `app/server.py`.

## Never

- Hand-edit `app/proto/*_pb2*.py` — it is generated by `protoc`.
- Add a dependency to the core `dependencies` list when an extra would do.
- Commit secrets. `.env` is gitignored; `.env.example` is the template.
- Change the model's licence posture: the code is Apache-2.0, the weights are
  under the Gemma Terms of Use.
